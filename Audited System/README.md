# Audited System

Short description

Security audit notes, findings, and remediation guidance for systems you have assessed. Use this folder for full audit reports, checklists, and evidence (redacted where necessary).

## Objective
Collect audit scope, methodologies (e.g., OWASP ASVS, CIS Benchmarks), and executive summary.

## Contents
- reports/ — PDF or markdown audit reports
- tools/ — scripts used during the audit (scans, parsing)
- evidence/ — screenshots and logs (redacted)

## Responsible Disclosure
If you discovered high-severity vulnerabilities in third-party systems, follow responsible disclosure procedures — avoid publishing exploit details until fixes are available.

## Notes & Safety
- Redact sensitive identifiers before committing (IPs, usernames, secrets).
- Keep live testing activity within authorized scope only.
