# Contributing

Thanks for your interest in contributing to Cybersecurity-Projects! We welcome contributions that improve documentation, add new projects, fix typos, or provide reusable tooling.

How to contribute

1. Fork the repository.
2. Create a new branch: `git checkout -b my-feature`.
3. Add your project or changes. If adding a project, include a README that follows the project template in the root README.
4. Commit your changes with a clear message and push the branch.
5. Open a pull request describing what you changed and why.

PR checklist

- [ ] My changes follow the repository's style and guidelines.
- [ ] I added or updated documentation where applicable.
- [ ] I did not include sensitive data (passwords, private keys, real credentials).
- [ ] For code additions, include tests where reasonable.

Security & sensitive data

- Do not commit secrets, private keys, or any personally-identifiable information.
- If you believe you've found a security vulnerability in content present here, open a private GitHub Security Advisory or contact the repository owner directly instead of creating a public issue.

Code style

- Use clear, minimal dependencies where possible.
- Prefer small, focused commits and an explanatory PR description.
